# FinDocs AI

Financial Document Intelligence & Research Assistant.

## Overview

FinDocs AI is an AI-powered platform designed
to extract, analyse and retrieve information
from financial documents.

## Planned Features

- PDF document processing
- Financial table extraction
- RAG-based question answering
- Source citations
- Financial calculations
- Multi-document comparison
- Interactive financial dashboards

## Technology Stack

- Python
- PyMuPDF
- pdfplumber
- Pandas
- NumPy
- ChromaDB
- LangChain
- FastAPI
- Streamlit
- PostgreSQL

Currently under development.
